# Página de venda: BPO Lab - Ferramentas

Página estática (um arquivo `index.html`) publicada na Vercel.

- Na Vercel, o projeto usa **Root Directory = `landing-ferramentas`**, sem framework e sem build.
- Botões de compra apontam para o checkout da Cakto: https://pay.cakto.com.br/pxhnbp7
- Enquanto a compra de teste não passar, a página fica com `noindex` (fora do Google). Tirar a linha `<meta name="robots" ...>` quando liberar.
